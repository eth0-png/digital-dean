## 2026-11-07, этап: день 1, выкладка на сервер

Инструмент: Claude Code (Claude Opus 5.5), SSH, браузер приложения Claude для проверки на 360 px.

Просили: выложить заглушку на машину Cloud.ru, которую создала команда. Позже: разобраться, почему SSH отваливается по таймауту.

ИИ сделал:
- Нашёл причину таймаута. Порты 81 и 5555, закрытые в фаерволле облака, тоже «открывались» мгновенно, значит, соединение принимал кто-то на этом компьютере. Маршрут до IP сервера шёл через адаптер `happ-xray` VPN-клиента Happ. Настройки VPN ИИ менять не стал, предложил команде два варианта.
- Проверил сервер: Ubuntu 24.04, вход только по ключу (пароль уже выключен настройкой образа), sudo без пароля.
- Поставил Docker и Compose из репозитория Ubuntu. Проверил, что с сервера доступны Docker Hub, GitHub, npm и Let's Encrypt, зеркала не понадобились.
- Выложил заглушку: https://87.242.100.109.sslip.io, сертификат Let's Encrypt через Caddy, HTTP перенаправляет на HTTPS, ответ около 40 мс.

Что пошло не так:
- Таймаут SSH из-за VPN на компьютере команды (см. выше).
- Сборка Docker упала: пустая папка `public` не попала в git. В Dockerfile добавили `mkdir -p public`.
- Caddy объявлял HTTP/3, а UDP 443 в фаерволле закрыт. Браузер мог тратить время на попытку, HTTP/3 выключили.
- Скриншот Chromium без окна на 360 px обрезан справа: он не даёт окно уже примерно 500 px ни в новом, ни в старом режиме. В браузере приложения проверили: ширина страницы 360 из 360, вёрстка не вылезает. Для скриншотов в день 2 нужен скрипт, который задаёт ширину страницы напрямую.

Исправили вручную: команда завела аккаунт Cloud.ru, создала машину, открыла порты, обновила пакеты и добавила IP сервера в исключения VPN. Команда проверила сайт с телефона через мобильный интернет без VPN: открывается быстро. Вопрос команды «открыть UDP ради HTTP/3?» решили не открывать: выигрыш десятки миллисекунд только на повторных соединениях, а QUIC в российских мобильных сетях иногда режется.

Скриншоты: `docs/screenshots/2026-11-07-deploy-placeholder-неудачно.png` (обрезанный скриншот).

## 2026-11-07, этап: выбор дизайна, разбор дизайн-скиллов, сравнение хостингов

Инструмент: Claude Code (Claude Opus 5.5), скилл `ui-ux-pro-max` (локальный поиск по базе стилей и UX-правил), веб-поиск по тарифам.

Просили: дизайн Б понравился. Посмотреть установленные дизайн-скиллы и сказать, что применить. Сравнить Yandex Cloud и Cloud.ru по цене, понять минимальный сервер, выбрать регистратора домена.

ИИ предложил:
- Карту скиллов по этапам (в `PLAN.md`, раздел 9): токены и компоненты в день 2, тексты состояний через `design:ux-copy`, проверка доступности и разбор экранов перед ранней отправкой.
- Минимальный сервер: во время работы хватает 1 ГБ, сборке нужно 1,5–2 ГБ. Таблицу цен Cloud.ru и Yandex Cloud: Cloud.ru в 1,5–2 раза дешевле при той же машине. Yandex выгоднее, только если там действует грант нового клиента, а бонусы Cloud.ru уже израсходованы.
- Домен у регистратора с входом через Госуслуги: с 1 сентября 2026 это обязательно для .ru.

Что пошло не так:
- Автоматический подбор дизайн-системы в `ui-ux-pro-max` для запроса «студенческий портал» выдал шаблон лендинга магазина приложений, «глиняный» стиль для детских приложений, розовую палитру и моноширинный шрифт Fira Code. Это не подходит, отвергли. Полезной оказалась база UX-правил и чек-лист.
- Скиллы 21st: CLI установлен, но токен не действует (ошибка 401). Без повторного входа они не работают.
- Цены из обзоров расходятся между собой (например, цена публичного IP в Yandex). В таблице помечено «сверить в калькуляторе».

Исправили вручную: выбор варианта Б сделала команда. Хостинг выбрала команда: новый аккаунт Cloud.ru на сокомандника ради бонуса 4000 и машина 2 vCPU 100% / 4 ГБ вместо рекомендованных 30%, с запасом по скорости для жюри.

Скриншоты: нет.

## 2026-11-07, этап: день 1, каркас, репозиторий, хостинг, варианты дизайна

Инструмент: Claude Code (Claude Opus 5.5), субагент для чтения документации Cloud.ru, Chromium в режиме без окна для скриншотов.

Решения команды перед этапом: идея А «Справка как посылка» плюс «запросить уточнение» и «нашли ошибку в данных». Минимальный кабинет сотрудника. Хостинг Cloud.ru. Публичный GitHub. На документе и странице проверки пометка «Демо, юридической силы не имеет». Каркас экрана «Сегодня» в день 2, наполнение в день 6. Ответ опроса от 06.11 14:04, по мнению команды, заполнен через ИИ, исключаем его.

Просили: «Начинай день 1».

ИИ предложил и сделал:
- Отдал субагенту чтение официальной документации Cloud.ru. Вывод: Container Apps даёт HTTPS и минимум 1 экземпляр, но базу в нём держать нельзя. Managed PostgreSQL стоит тысячи рублей в месяц, и в документации нет, как к нему подключиться из Container Apps. Бесплатная машина Free Tier получает только 10% процессора. Предложил одну обычную виртуальную машину с Docker Compose (приложение, PostgreSQL, Caddy для HTTPS).
- Каркас Next.js 16.4.5 с заглушкой и плашкой «концепт», сборка standalone в Docker, `docker-compose.yml` и `Caddyfile`.
- Публичный репозиторий https://github.com/eth0-png/digital-dean. Сырые ответы опроса `research/survey.csv` не публикуются, в репозитории только сводка.
- Три варианта главного экрана на 360 px с одинаковым содержимым из опроса: А спокойный светлый, Б яркий с градиентной карточкой пары, В тёмный строгий.

Что пошло не так:
- Next.js 16 новее знаний модели. Шаблон сам кладёт `AGENTS.md` с требованием читать документацию из `node_modules/next/dist/docs/`. Добавили это правило в `CLAUDE.md`.
- `create-next-app` не создаёт проект в папке с нашими файлами. Собрали во временной папке и перенесли.
- `tsc --noEmit` упал на `LayoutProps`: в Next.js 16 типы маршрутов генерируются отдельно. Команда проверки типов теперь `next typegen && tsc --noEmit`.
- Статья на Хабре называет адрес Container Apps `*.containers.cloud.ru`, а документация `*.containerapps.ru`. Статьи устаревают, сверяемся с документацией.
- Шаблонный `.gitignore` скрывал и `.env.example`. Добавили исключение.
- `npm audit`: 8 уязвимостей средней важности в зависимостях линтера. Они только для разработки и в образ не попадают.
- Вариант А: логотип читается как латинская «A», а не «Д». Вариант В: полупрозрачное нижнее меню просвечивает текст пар под ним. Вариант Б: белый мелкий текст на светлом конце градиента близок к границе контраста AA.

Исправили вручную: решения команды выше. Код руками не правили.

Скриншоты: `docs/screenshots/2026-11-07-design-variant-a.png`, `-b.png`, `-c.png`. Макеты: `docs/design/`.

## 2026-11-07, этап: исследование и план

Инструмент: Claude Code (Claude Opus 5.5), десктопное приложение Claude.

Просили: прочитать задание и опрос, посчитать ключевые цифры, сделать сводку опроса, план с 2–3 вариантами сильной идеи, стек и хостинг, этапы по дням с контрольной точкой 15 ноября, правила для ИИ и файл статуса. Код не писать. Ключевая часть промпта дословно:
