## 2026-11-07, этап: навигация «назад» и закрытие профиля

Инструмент: Claude Code (Claude Opus 5.5), Chromium через puppeteer-core.

Просили: «Из профиля „Нашли ошибку в данных“, а стрелка назад уводит в „Документы“, лучше в профиль. ИИ сделал:
- Написал `scripts/check-nav.mjs` по сценариям команды и прогнал на сервере до исправления: 9 ошибок, баги воспроизведены.
- Нашёл причину «не найдено»: при открытии профиля запоминался только путь страницы без параметров, `/documents/new` вместо `/documents/new?type=data_fix`, а форма без типа отвечает «не найдено».
- Сделал общий механизм вместо заплаток: кабинет помнит путь по страницам с полными адресами. «Назад» ведёт на предыдущую страницу и подписан её именем («Профиль», «Мои заявки», «Документы»), отправленную форму пропускает. Профиль и уведомления закрываются на полный адрес, откуда их открыли.

Что пошло не так:
- Первая версия считала возвратом любое повторное открытие страницы, которая уже была в пути. Цепочка «профиль → форма → снова профиль» забывала форму. Теперь возврат определяется по действию: «назад», закрытие профиля или уведомлений, кнопка «назад» браузера.
- Вторая ошибка: адрес возврата считается при отрисовке, когда новая страница ещё не записана в путь, а поиск находил более раннее посещение того же профиля. Теперь текущая страница считается записанной, только если она последняя.
- Обе ошибки нашёл тот же скрипт, без него они дошли бы до команды.
- Третью ошибку нашла команда: «Сегодня» → профиль → исправление данных → «назад» → повторный тап по аватарке возвращал в форму, а не закрывал профиль. Причина: кнопка в шапке считает адрес возврата при отрисовке, после «назад» отрисовалась раньше, чем путь обновился, и больше не пересчитывалась. Теперь кнопки в шапке и «назад» подписаны на изменения пути (`useSyncExternalStore`). Сценарий команды и ещё один похожий («заявка → справка → назад → назад») добавлены в `check-nav.mjs`. Скрипт сначала воспроизвёл ошибку на сервере, после исправления все 35 сценариев проходят.

Исправили вручную: команда нашла баги на телефоне и описала сценарии.
